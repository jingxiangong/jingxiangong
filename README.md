## Selected Work

### [Multimodal Pupillometry Preprocessing](https://github.com/jingxiangong/multimodal-pupii-preprocessing)

Research-related Python code for preparing pupil-diameter and multimodal measurements for analysis. The workflow includes invalid-value filtering, median absolute deviation (MAD) and moving-average-based outlier handling, interpolation methods (PCHIP, Akima, and Makima), and timestamp-based data integration.

**Tools:** Python, pandas, NumPy, SciPy, scikit-learn, matplotlib
